# ADR-004. CQRS básico sin base de datos separada; el handler es el método del servicio

**Estado:** Aceptada

## Contexto
Las consultas de disponibilidad, estado de devolución y criterio vigente no necesitan reconstruir aggregates y requieren un modelo de lectura distinto.

## Alternativas
Un solo modelo para lectura y escritura; CQRS completo con bus y base separada; CQRS básico con handlers como métodos.

## Decisión
Commands por los Application Services; Queries por ConsultasDeInventario y ConsultasDeDevoluciones, que usan lectores y devuelven DTO. Sin bus ni mediador.

## Consecuencias
Beneficio: lecturas simples y rápidas, escritura protegida. Costo: dos caminos que mantener alineados; si el volumen crece se puede evolucionar a un almacén de lectura sin cambiar los contratos.

## Trazabilidad
BR-001; US02, US04, US05, US16.
