# ADR-007. Specification para las reglas de negocio combinables

**Estado:** Aceptada (nueva en el PIA)

## Contexto
El PIA exige Specification. Las reglas de apartado, venta y devolución se combinan (por ejemplo, un producto apartable Y una unidad disponible Y un anticipo suficiente) y deben explicar por qué fallan. En U3 las reglas de devolución eran estrategias sueltas (ADR-005).

## Alternativas
Condicionales dentro de las entidades; reglas como métodos estáticos; interfaz Specification con composición Y, O y No.

## Decisión
Interfaz IEspecificacion con EsSatisfechaPor, que devuelve un ResultadoDeRegla con la razón, y composiciones Y, O y No. Especificaciones concretas: producto apartable, unidad disponible para venta, apartado vigente, método de pago autorizado, comprobante válido, devolución dentro de plazo y condición aceptable. Las reglas de devolución (ADR-005) se apoyan en estas especificaciones.

## Consecuencias
Beneficio: reglas reutilizables, combinables y probables de forma aislada; el dictamen explica cada incumplimiento. Costo: más clases pequeñas y disciplina para no duplicar la condición dentro de la entidad.

## Trazabilidad
RN-APT-003, RN-APT-004, RN-VTA-002, RN-DEV-001, RN-DEV-002, RN-DEV-003; US01, US06, US10; requisito del PIA (Specification).
