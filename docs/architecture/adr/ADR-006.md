# ADR-006. Modelo de rechazo: excepción de dominio, resultado con derivación y rechazo con efecto

**Estado:** Aceptada

## Contexto
Los rechazos tienen significados distintos: unos no dejan rastro, otros dejan la devolución en revisión y otros deben guardar el vencimiento de un apartado.

## Alternativas
Excepciones para todo; códigos de retorno para todo; combinar según el tipo de rechazo.

## Decisión
Violación de regla: ReglaDeNegocioViolada (rollback). Derivación: estado válido EnRevision. Rechazo con efecto: ResultadoDeConversion rechazada y Confirmar(). TraductorDeRechazos genera el Rechazo con alternativa sugerida.

## Consecuencias
Beneficio: errores expresados en términos del negocio y cada caso alterno es explícito. Costo: el equipo debe distinguir los tres tipos al crear reglas nuevas.

## Trazabilidad
US06, US10, US13, US20; RN-APT-002, RN-DEV-001/002, RN-SUP-002.
